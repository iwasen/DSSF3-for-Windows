▼主な機能

「DSSF3」の構成プログラムは「リアルタイムアナライザ」（RA）、「サウンドアナライザ」（SA）、「環境騒音アナライザ」(EA)の3つです。

・RA [2ch対応 リアルタイムアナライザ]
1. ピークレベルメーター
2. シグナルジェネレーター
3. パワースペクトラム
4. オクターブ分析 (1/1 1/3 1/6 1/12 1/24)
5. 騒音計（キャリブレーシヨンが必要）
6. 3次元グラフ表示
7. オシロスコープ
8. 歪率計
9. 位相計
10. 自己相関相互相関リアルタイム表示
11. スペククトグラム表示
12. インパルス応答測定機能
13. ランニングACF測定機能
14. レコーダー　プレーヤー

・EA [2ch対応 環境騒音アナライザ]
1. タイマーによる時間指定による自動測定機能
2. 指定音量を超えると自動測定する機能
3. 音響パラメーターによる騒音源同定機能

・SA [2ch対応 サウンドアナライザ]
1. インパルス応答分析
2. ランニングACF分析
3. 環境騒音測定データの分析

■動作確認

▼リアルタイムアナライザ

「スタート」メニューの「音響分析システム 5J」から「リアルタイムアナライザ」を選択して起動してください。ダイアログから「試用」ボタンを押してください。

１．「リアルタイムアナライザ 」のウィンドウから「入力選択」を行います。外部マイクなどではなく、内部の音声信号を受け取るよう設定するのですが、このコントロール名はパソコンの機種によって異なります。

２．次に、Windowsのボリュームコントロールを開いて、「再生」をやはり、WAVEにします。マイクなどの入力は、ミュートしておきます。それは、シグナルジェネレーターの音だけを出したいからです。

３．メインウィンドウから「シグナルジェネレータ」ボタンをクリックします。「周波数」は1000Hz、「波形」は正弦波、「出力レベル」の「連動」をチェックしてから、レベル調整を０から若干上げて「開始」ボタンを押します。パソコンのスピーカーから”ピー”という音が聞こえてくるはずです。

４．メインウィンドウの「ピークレベルモニタ」の「入力」をチェックしてから、「オシロスコープ」ボタンを押してください。オシロスコープの右下の「開始」ボタンを押します。画面に正弦波が表示されるはずです。波形の頂上が崩れている場合は過大入力です。メインウィンドウの「入力Vol.」を少し下げて「ピークレベルモニタ」の「入力」信号が0dbより小さくなるように調整してください。

ここまでの動作が確認できたなら、出力、入力ともに正常です。


異常な場合

Windowsのバージョンによる場合

すべての動作が確認されたシステムですから。

うまくいかな場合は、主にWindowsのバージョンかインストールの問題です。だいたいその次がサウンドボードです。症状としては正常に、登録NOを入れても、正常に登録できなくて、毎回登録NOを要求される場合とか、うまく起動が出来ない場合です。エラーメッセージにもよりますが、多くは正しくインストールされていない場合です。多くはWindows９８の２ｎｄエディション、以前のWindowsの場合におこります。しかしその場合の問題は、多くはWindowsアップデートがしてない方で、多くは最新のソフトをインストールするときに、常に問題が起きるはずです。Windows update をあいてるときにかけて、付属するインストーラーなどを、最新にします。エクスプローラーやマイクロソフトオフィス等の新しいバージョンが入っていれば、大丈夫ですが。それでも稀にWindowsアップデートが必要なことがあります。
インストールしなおすときは、windowsのコントロールパネルから、DSSF3の最新のインストールモジュールを消さなくてはいけないので、アプリケーションの追加と削除を選んで、いったん 「Diagnostic System for Sound Fields Version 5J 」を完全に削除してから新規にインストールしなおしてください。

古いマシーンの場合うまくいかなくて、新しいマシーンに入れてみて動く場合は、無理をせず、新しいマシーンでご使用下さい。測定システムというソフトの性質上、高性能に向けてチューニングされています。


サウンドボードの設定による場合

サウンドブラスター仕様、サウンドブラスターコンパチ仕様OKのため、DELL,CONPAQ,SONY、TOSHIBA,NEC、FUJITSU.IBMなどほとんどすべてのサウンドカード、USB、ローランドなどのサウンドモジュールでも、さらにデジタル入力さえもそのまま使用できます。Windowsのサウンドインターフェースであれば、そのまま動きます。まれにデジタル入力カードなどで、拡張モードがデフォルトのものは、そのハードのスイッチを、Windowsインターフェースに直してやらないと動きません。基本的にはパソコン用のサウンドカードで、Windowsインターフェースを満足しないものなど、いまどきないので、動かない場合はサウンドカードや、パソコンの故障が考えられます。別のパソコンを使用して、測定してみないとわからない場合があります。

同時に特殊なサウンドカードを使用している場合、そのボードが、Windowsのルールを守らない場合にはそれらを利用した、測定用特殊ソフトと、同時動作できないことがあります。その場合は、それらのサウンドカードを抜くと、うまくいくことがあります。その場合は同居は無理ですから、別のマシーンを使用してください。

どちらにしろうまく動かない場合はサポートしますのでご連絡をください。メールや直接電話でサポートさせていただきます。

特別なハードウエアや、故障などの理由で、設定だけではうまく動かない場合もあります。
その場合は、動くマシーンを選択ください．主に計測事例などで使用されているマシーンはすべて、何もせずに動きます。

測定器として動作させるためには正確には、プログラムマニュアルにしたがって、各種入力ボリュ－ムなどの初期設定を行ってください。

■インストール方法

ダウンロードファイルを実行してください。

１．InstallShieldウィザードが立ち上がりますので「次へ」をクリックします。
２．使用許諾契約書が表示されますので、画面をスクロールして全文お読みいただいた上で「使用許諾契約の条項に同意します」をクリックすると「次へ」を押すことができるようになります。同意いただけない場合はここでインストールを中断してください。
３．「ユーザ名」と「所属」を入力して（あるいは確認して）「次へ」を押してください。
４．インストール先のフォルダはC:\PROGRAM FILES\DSSF5Jになっています。他のフォルダにインストールしたい場合は右の「変更」ボタンを押してインストール先フォルダを指定してください。「次へ」を押します。
５．セットアップタイプを選択します。通常は「標準」で「次へ」を押してください。
６．インストールの設定内容が表示されます。確認のうえ「インストール」ボタンを押してください。インストールが開始されます。
７．「InstallShieldウィザードを完了しました」と表示されたならインストールは完了です。「完了」ボタンを押してダイアログを閉じてください。
